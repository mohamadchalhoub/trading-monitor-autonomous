  This implementation’s zero-denominator convention:
    rsiFromAverages(gain=1, loss=0) = 100
    rsiFromAverages(gain=0, loss=0) = 100   <- fully flat series

    standard formula, else report 100 — including when average gain is also 0.

## 3. Synthetic series (this implementation)

  MetaTrader’s iRSI computes over a symbol’s chart data, so an arbitrary
  synthetic array cannot be fed to it. These are this implementation’s outputs,
  reported for the specific cases asked about; the terminal comparison above is
  what establishes the implementation is faithful in the first place.
    entirely flat initialised history              -> 100.000000
    rising, then five flat closes                  -> 100.000000
    mixed, then five flat closes                   -> 54.545455
    falling, then five flat closes                 -> 0.000000

    Note the third case: a mixed history leaves a NON-zero smoothed average loss,
    which decays but never reaches zero, so five flat closes raise RSI without
    pinning it to 100. Only a history with no downward change at all does that.
